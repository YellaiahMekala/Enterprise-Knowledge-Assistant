# Information Security Policy

## Passwords
Passwords must have at least 14 characters. Multi-factor authentication is mandatory for every account that can reach company data.

## Keys and secrets
Service account keys are rotated every 90 days. Secrets are never stored in source code or chat messages; use the secrets manager.

## Devices
All laptops use full-disk encryption. USB storage devices are blocked by default. A lost or stolen device must be reported to the security desk within 1 hour.

## Phishing
Report suspicious emails with the Report Phishing button. Do not click links or open attachments from unknown senders.
